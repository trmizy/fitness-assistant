# Training-only dependencies for train_qlora.py / export_adapter_to_ollama.py.
# NOT part of the product's runtime dependency graph (ai-service is Node/TS).
#
# Pivoted 2026-07 from the RunPod A40 + Qwen3-30B-A3B setup (see
# RUNPOD_RUNBOOK.md, now historical/optional) to LOCAL training on a
# consumer GPU with ~4GB VRAM, using Unsloth (purpose-built for low-VRAM
# QLoRA — meaningfully lower memory than raw transformers+peft+bitsandbytes
# for the same job) and a much smaller base model (Qwen2.5-1.5B-Instruct,
# see configs/qlora_coach_qwen2.5_1.5b.yaml).
#
# Exact versions below were installed and verified working together on
# Windows + Python 3.11 + CUDA 12.6 + RTX 3050 Ti (4GB). Pinned because
# getting here required fighting real dependency drift — `pip install
# unsloth` alone pulls a CPU-only torch wheel from PyPI (CUDA builds only
# exist on download.pytorch.org's own index), and reinstalling torch
# afterward without ALSO pinning torchvision to the matching release causes
# an ABI mismatch (`torchvision::nms does not exist` / triton
# `AttrsDescriptor` import errors). Install in this exact order:
#
#   uv venv --python 3.11 .venv
#   uv pip install --python .venv unsloth numpy
#   uv pip install --python .venv torch==2.10.0 torchvision==0.25.0 \
#       --index-url https://download.pytorch.org/whl/cu126 \
#       --reinstall-package torch --reinstall-package torchvision
#
# (cu126 chosen because cu129 has no Windows wheel as of this writing; any
# driver reporting CUDA >=12.6 — check with `nvidia-smi` — works fine, CUDA
# runtime wheels are backward compatible with newer drivers.)
