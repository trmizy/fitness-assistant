## Weak Sources Replaced

- Generic agent-framework comparison blogs should not be used as primary evidence for adopting or rejecting LangGraph-like frameworks. Use Anthropic's production guidance and Gymini's own code/test evidence instead.
- Community chunking tutorials should not justify RAG changes alone. Use Gymini's reproducible retrieval eval plus empirical RAG papers.
- ResearchGate/Academia-style reposts should be avoided when official docs, arXiv papers, or standards documents are available.

## Notes

External research supports the evaluation stance, but code remains the source of truth for Gymini behavior. Research sources should guide what to test and how to frame risk; they do not prove Gymini is safe without local tests.
