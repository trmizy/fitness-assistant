## 2. Per-route inventory (after)
All 19 routes x 3 variants (57): axe serious+critical = **0** except the dispute page (owned elsewhere, not edited; 3 combos). Before: 9 violations. One `h1`, one `main`, one `aside`, one `header` on every page I own; 2-3 `nav` landmarks, all labelled (`Điều hướng quản trị`, `Đường dẫn`, `Tài chính`, `Phân trang`). The skip link is the first Tab stop, becomes visible (203x36), Enter focuses `<main>`. Keyboard walk: up to 70 Tab stops per page, indicator on every stop, no hidden/off-screen focus, no positive tabindex. Notification bell: Enter opens, Esc closes and returns focus. Mobile drawer: traps focus across 40 Tabs, Esc closes, focus returns to the menu button. Money dialog (withdrawals approve): named, traps focus, Esc, focus returns to opener. Live regions: `role=status` on loading skeletons/tiles; 0 buttons/links without an accessible name.
Motion inventory: page fade 160 ms (opacity + 6 px, duration 0 with reduced motion — already in `AdminShell`), sidebar width 200 ms, drawer 200 ms, nav/hover colour 150 ms, Radix dialog 150-200 ms, skeleton pulse 2 s, spinners 1 s; no count-up, no row animation, no animation that delays reading a number. All state-change transitions <= 200 ms.
Polling: Today 13 queries / 60 s (users 5 min), Reconciliation 4 / 60 s, Overview 1 / 60 s, topbar notifications 2 / 60 s, nav badges share the page query keys (deduped by react-query); AI and System page-local 30 s intervals (F12).
